# Group-9-Project-9-Ghana-Road-Network-

This project is a C++ application developed for INF311 (Data Structures). It demonstrates how graphs and linked-list adjacency lists can be used to represent and manage road connections between major cities in Ghana.

Key Features:

- Add and remove cities and roads.
- Search for cities.
- Display the road network.
- Check connectivity between cities.
- Perform Breadth-First Search (BFS) and Depth-First Search (DFS).
- Visualise the network using SFML.

Technologies: C++, SFML 2.6.2 and Code::Blocks.

*Note: The Ghana map is illustrative and is used to demonstrate graph operations.*
